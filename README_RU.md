# ScreenFlip PSP — исходный проект / прототип

Цель: PSP-2000, CFW 6.61 ARK-5, режим GAME, переключение SELECT,
поворот изображения на 180 градусов.

## Честный статус

Это **собираемый каркас PRX**, а не готовый рабочий экранный переворот.
В нём реализованы:
- PRX entry points `module_start` / `module_stop`;
- поток опроса SELECT с переключением состояния ON/OFF;
- отдельная функция преобразования framebuffer на 180° для 16- и 32-битных пикселей.

В нём **ещё нет интеграции преобразования в реальный графический вывод игры**.
Поэтому собранный PRX не следует считать готовым ScreenFlip: он переключает
состояние, но не меняет ориентацию изображения. Не устанавливайте его как
готовый функциональный плагин и не тестируйте на единственной карте/консоли.

## Почему нельзя честно дописать универсальный hook наугад

`sceDisplaySetFrameBuf` задаёт адрес framebuffer, ширину буфера и формат
пикселей. Но игры PSP обычно рендерят через Graphics Engine (GE), могут
использовать разные буферы, stride, форматы и схемы двойной буферизации.
Один перехват `sceDisplaySetFrameBuf` не гарантирует захват каждого кадра.
Для надёжной реализации нужен совместимый с конкретной версией ARK-5
механизм kernel/import hook и проверка на реальной PSP-2000.

Не следует подменять framebuffer без корректного кэша, синхронизации GE/VBlank
и проверки формата/stride: это может вызвать артефакты, чёрный экран или
зависание.

## Сборка

Нужен установленный PSPSDK с MIPS toolchain и переменной `PSPSDK`.

В Linux/WSL:
```sh
export PSPDEV=/usr/local/pspdev
export PSPSDK=$PSPDEV/psp/sdk
export PATH=$PATH:$PSPDEV/bin
make clean
make
```

Результат SDK-сборки — `screenflip.prx` (и служебные файлы сборки).
Сборка не была выполнена в этой среде: PSPSDK здесь не установлен.

## Установка (только после завершения display-hook)

Для ARK-5 используйте менеджер плагинов ARK или запись в
`ms0:/SEPLUGINS/PLUGINS.TXT`:
```text
game, ms0:/seplugins/screenflip.prx, on
```

На старых PRO/ME-подобных конфигурациях используется `GAME.TXT`.
ARK-5 может импортировать старые конфиги, но предпочтителен собственный
менеджер/формат `PLUGINS.TXT`.
